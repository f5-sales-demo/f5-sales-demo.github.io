Choose a demonstration or capability guide, then check its deployment requirements and verification steps. Demo guides include implementation workflows; capability guides explain a feature and its scenarios.

[Demo environment](https://f5-sales-demo.github.io/demo-resources/en/) provides supporting infrastructure. [Ecosystem directory](/en/ecosystem/) includes tools and project sources.

## Security

- [Web App & API Protection](https://f5-sales-demo.github.io/webapp-api-protection/en/) — Deploy an application security demo with Terraform and follow its protection walkthroughs. **Demo guide.**
- [API Protection](https://f5-sales-demo.github.io/api-protection/en/) — Find guides to API discovery, schema validation, and request controls. **Capability guide.**
- [Bot Defense Advanced](https://f5-sales-demo.github.io/bot-advanced/en/) — Review behavioral bot detection and mitigation scenarios. **Capability guide.**
- [Bot Defense Standard](https://f5-sales-demo.github.io/bot-standard/en/) — Review bot classification, verified crawlers, and blocking policies. **Capability guide.**
- [Client-Side Defense](https://f5-sales-demo.github.io/csd/en/) — Deploy browser script monitoring with an API or Terraform workflow. **Demo guide.**
- [DDoS Mitigation](https://f5-sales-demo.github.io/ddos/en/) — Review distributed denial-of-service defenses and demo scenarios. **Capability guide.**
- [Web App Scanning](https://f5-sales-demo.github.io/was/en/) — Find web application vulnerability scanning guides. **Capability guide.**
- [Custom responses](https://f5-sales-demo.github.io/custom-responses/en/) — Configure application replies, redirects, and security response pages. **Demo guide.**
