## Demo environment

Choose the deployment that fits your demonstration. Azure and Amazon Web Services (AWS) offerings have different workloads and runtimes; check each guide before provisioning.

- [Demo resource catalog](https://f5-sales-demo.github.io/demo-resources/en/) — Choose origin, traffic, and CDN simulation resources for a demo environment.
- [Origin server](https://f5-sales-demo.github.io/origin-server/en/) — Compare the Azure full-origin stack with the separate AWS Juice Shop deployment.
- [Traffic generator](https://f5-sales-demo.github.io/traffic-generator/en/) — Choose Azure or AWS deployment guides for controlled security traffic and browser scenarios.
- [CDN simulator](https://f5-sales-demo.github.io/cdn-simulator/en/) — Deploy an Azure proxy that adds CDN headers to origin requests.
